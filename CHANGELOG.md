# Changelog

## 0.1.0-alpha.1 — 2026-07-28

- Established the clean `GZG-NOW` product boundary.
- Added a dependency-free, GitHub Pages-ready browser alpha.
- Implemented local ORACLE Ghost and claimed-session credentials with Ed25519.
- Implemented canonical serialization, SHA-256 identifiers, and signed events.
- Implemented the scaled d10 check, threat confirmation, and strict Base-10 AP.
- Implemented DEALER cards that carry modifiers rather than absolute AP.
- Implemented deterministic MARK challenges.
- Implemented browser-local P2Pm artifact proof-of-work.
- Added replay export, chain/signature verification, tests, and deployment workflow.
- Kept JOKE, NEURAL, wallet, and masternode adapters explicitly unimplemented.
