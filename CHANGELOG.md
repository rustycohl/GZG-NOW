# Changelog

## 0.1.0-alpha.3 — 2026-07-28

- Established the first audience-facing release as two standalone products
  (`BattleStarSol`, `X-Command`) plus one rules reference (`d10SRD`).
- Classified GZG:NOW and the remaining live Pages as the public development
  and backend-test network.
- Added a machine-readable product registry and publication hierarchy tests.
- Promoted d10SRD to a readable public reference without removing its
  independent executable port role.

## 0.1.0-alpha.2 — 2026-07-28

- Added the independent server-card port contract: one card, one repository,
  one live GitHub Pages surface.
- Added the six working vertical-slice ports to the public card registry.
- Published every working port as its own repository and GitHub Page.
- Locked the naming boundary: Ground Zero Gaming publishes the Creative
  Commons documents; Ground Zero Games ships the runnable products.
- Added executable registry tests for dedicated, unique repo/Page flags.
- Added MIT as the canonical v0.1 software option while preserving the
  irrevocable Apache-2.0 grant from the initial publication.
- Incorporated the late-arriving resolved architecture and master plan into
  the provenance register.

## 0.1.0-alpha.1 — 2026-07-28

- Established the clean `GZG-NOW` product boundary.
- Added a dependency-free, GitHub Pages-ready browser alpha.
- Implemented local ORACLE Ghost and claimed-session credentials with Ed25519.
- Implemented canonical serialization, SHA-256 identifiers, and signed events.
- Implemented the scaled d10 check, threat confirmation, and strict Base-10 AP.
- Implemented DEALER cards that carry modifiers rather than absolute AP.
- Implemented deterministic MARK challenges.
- Implemented browser-local P2Pm artifact proof-of-work.
- Added replay export, chain/signature verification, tests, and deployment workflow.
- Kept JOKE, NEURAL, wallet, and masternode adapters explicitly unimplemented.
