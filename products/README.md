# Standalone products

Each child directory is an independent Git repository and GitHub Pages
product. The parent `GZG-NOW` repository tracks only this map.

## Initial audience-facing release

1. [`BattleStarSol`](https://rustycohl.github.io/BattleStarSol/) — the themed
   launch page for a clean browser tab.
2. [`X-Command`](https://rustycohl.github.io/X-Command/) — the standalone
   deterministic tactical-generator product demo.
3. [`d10SRD`](https://rustycohl.github.io/d10SRD/) — the Creative Commons rules
   reference and executable conformance surface.

GZG:NOW and the independent server-card Pages remain live and open for public
inspection, but primarily serve integration and backend testing.
